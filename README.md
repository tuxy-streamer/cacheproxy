# cacheproxy

A caching proxy server that caches requests and sends them to the original server

```bash
caching-proxy --port <number> --origin <url> --clear-cache

--port is the port on which the caching proxy server will run.

--origin is the URL of the server to which the requests will be forwarded.

--clear-cache is used to clear the existing cache.
```

Inspired from [roadmap.sh/projects/cache-server](https://roadmap.sh/projects/caching-server)
